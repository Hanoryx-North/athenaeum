# Athenaeum

<!-- impeccable:product-schema 1 -->

## Platform

desktop (Windows and macOS, Tauri webview)

## Users

People working on local projects with their existing coding agent.

## Product Purpose

Keep knowledge in a local Markdown wiki, review agent proposals, browse accepted pages and explicitly share with Library.

## Capabilities and Constraints

Tauri 2 and React 19. Local engine, CLI and bridge remain authoritative. Account credentials use existing CLI operations; the UI does not add another auth system.

## Brand Commitments

Confirmed by the user on 2026-10-28: modernize the current Library baseline, keep Roboto, blue/green accents and light/dark themes. Unify the admin, Library and desktop components. Sign-in and account management are dedicated screens.

## Accessibility & Inclusion

Keyboard access, visible focus, reduced motion, responsive layouts, clear error and loading states.

## Evidence on Hand

AGENTS.md and the current implementation. Existing API contracts and tests remain the behavior baseline.
